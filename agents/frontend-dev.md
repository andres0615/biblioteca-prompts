## Stack del proyecto
- React 19 + Vite 8, JavaScript plano (JSX). No usar TypeScript.
- CSS nativo con anidación y variables (`--*`) en `src/index.css`; tema claro/oscuro vía `prefers-color-scheme`. Estilos por componente en `src/App.css`.
- Sin framework de CSS, sin router y sin state management.

## Convenciones

- Mantener JSX; no proponer migración a TypeScript ni añadir `.tsx`.
- Responder siempre en español.
