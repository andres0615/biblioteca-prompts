# Completar requests para categorias

## 1. Cargar skill

- Carga la skill `read-files-constraints `

## 2. Leer archivos necesarios

Lee los siguientes archivos:

Archivos correspondientes al modulo productos:

- `app/Http/Requests/StoreProductRequest.php`
- `app/Http/Requests/UpdateProductRequest.php`

Archivos correspondientes al modulo supplier:

- `otros/db/product_category.sql`
- `app/Http/Requests/StoreProductCategoryRequest.php`
- `app/Http/Requests/UpdateProductCategoryRequest.php`

# 3. Generar plan para completar los requests de categorias

- Basandote en las el esquema y las convenciones de los archivos del modulo de productos, generaras un plan para completar los requests de categorias `StoreProductCategoryRequest.php` y `UpdateProductCategoryRequest.php`
